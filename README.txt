SYLLABUS TRACKER — INSTALLABLE WEB APP

This is a Progressive Web App (PWA) package.

IMPORTANT: Opening index.html inside ChatGPT's file preview will NOT run the app's JavaScript. It must be served from a web address (HTTPS) for proper PWA installation and offline service-worker support.

Files:
- index.html — app
- manifest.webmanifest — install metadata
- sw.js — offline cache

Once hosted over HTTPS:
1. Open the site in Safari on iPad.
2. Tap Share.
3. Tap Add to Home Screen.
4. Open the new Syllabus Tracker icon.

Data is stored locally in the browser on the device.
